# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that helps job seekers improve their resumes by providing intelligent feedback, ATS-friendly suggestions, and detailed analysis using modern AI technologies.

---

## 🚀 Features

- 📄 Upload resumes in PDF/DOCX format
- 🤖 AI-powered resume analysis
- 📊 ATS compatibility insights
- 💡 Personalized improvement suggestions
- 📝 Skill extraction
- ⚡ Fast and responsive UI
- 🔒 Secure file handling

---

## 🛠 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- Prisma
- PostgreSQL
- Docker
- Ollama / LLM Integration

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Nikhilkumar1103/AI-Resume-Analyzer.git
```

Move into the project

```bash
cd AI-Resume-Analyzer
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
